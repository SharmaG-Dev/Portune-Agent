# Portune Agent

Portune Agent connects an application running on your computer to the Portune tunnel network. It forwards requests from a server-assigned public URL to your local application and sends its responses back to the visitor.

Use it to share a local web application, demonstrate work in progress, or receive webhooks while developing. Your application and the agent must stay running for requests to reach your computer.

## What it does

- Connects to a Portune server using your agent token.
- Requests a public tunnel with a subdomain generated by the server.
- Forwards HTTP requests to the local URL you choose.
- Displays the public URL and request activity in your terminal.
- Automatically names the agent using its local IP and your configured name prefix.

## Use the downloaded agent

### 1. Extract your download

Extract the ZIP or TAR.GZ archive into a folder. The executable is `portune` on macOS/Linux or `portune.exe` on Windows. Open a terminal in that folder.

### 2. Add your connection details

You need access to a running Portune server and a valid agent token issued by its administrator. Create a file named `.env` in the folder where you run the agent:

```dotenv
PORTUNE_SERVER_URL=https://your-portune-server.example/tunnel
PORTUNE_AGENT_TOKEN=your-server-issued-token
PORTUNE_AGENT_NAME_PREFIX=portune
```

Replace the example URL and token with your connection details. Keep your token private. The name prefix produces an agent name such as `192.168.1.10-portune-agent`.

The agent reads `.env` from your terminal's current directory. Existing environment variables override values in this file.

### 3. Start your tunnel

Make sure your local application is running. Replace `http://localhost:4000` below with its address.

**macOS / Linux**

```sh
chmod +x ./portune
./portune agent --target http://localhost:4000
```

**Windows PowerShell**

```powershell
.\portune.exe agent --target http://localhost:4000
```

After authentication and tunnel creation, the terminal displays the public URL returned by the server. Open or share that URL to access your application. You do not need to choose a subdomain; the server assigns one. The tunnel's display name comes from the target hostname, such as `localhost`.

### 4. Stop your tunnel

Press `Ctrl+C` in the agent terminal to disconnect.

## Help and version

On macOS/Linux:

```sh
./portune --help

```

```powershell
.\portune.exe --help

```

## Troubleshooting

| Problem | What to check |
| --- | --- |
| A required setting is missing | Check the three values in `.env` and run the command from the folder containing it. |
| Connection or authentication fails | Confirm the server URL, server availability, and your agent token. |
| The public URL returns a 502 response | Confirm your local application is running and `--target` points to its correct address and port. |
| A download link does not work | Open the Releases page and check whether that platform's archive is available. |
