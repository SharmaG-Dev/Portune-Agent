# Portune Agent

Connect your local application to the Portune tunnel network and get a public URL generated by the server.

## Setup

1. Download and extract the archive for your platform when available.
2. Create a `.env` file in the directory where you will run the command. Use [.env.example](.env.example) as a template:

   ```dotenv
   PORTUNE_SERVER_URL=https://your-portune-server.example/tunnel
   PORTUNE_AGENT_TOKEN=your-server-issued-token
   PORTUNE_AGENT_NAME_PREFIX=portune
   ```

   Replace the example server URL and token with your own values. Keep your token private. Existing environment variables take precedence over `.env`.

3. Start your local application, then start the agent from the extracted directory.

   **macOS / Linux**

   ```sh
   chmod +x ./portune
   ./portune agent --target http://localhost:4000
   ```

   **Windows PowerShell**

   ```powershell
   .\portune.exe agent --target http://localhost:4000
   ```

The server assigns the subdomain and returns the public URL, which the agent prints in your terminal. Press `Ctrl+C` to stop the agent.

Optionally, place the executable in a directory on your `PATH` to run `portune agent --target http://localhost:4000` from your terminal. The `.env` file is still read from the current working directory, not the executable's directory.

## Run from source

Until release downloads are published, you can run from source with the Go version specified in [go.mod](go.mod):

```sh
git clone https://github.com/SharmaG-Dev/Portune-Agent.git
cd Portune-Agent
```

Create `.env` using the settings above, then run:

```sh
go run . agent --target http://localhost:4000
```

For the backend protocol and required server behavior, see [Server integration](docs/server-integration.md).
